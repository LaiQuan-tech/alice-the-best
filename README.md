## 技術

- **簡報引擎**移植自 `agec-pitch`：CSS `scroll-snap-type:y mandatory` 翻頁 + 兩組 `IntersectionObserver`（threshold 0.55 追蹤當前頁、0.18 觸發淡入）+ 頂部進度條 + 右側導覽點
- **鍵盤**：`↓` `PageDown` `Space` 下一頁｜`↑` `PageUp` 上一頁｜`Home` `End` 首末頁
- **色系**移植自 `interval/web/src/app/globals.css`（象牙沙龍）：`#faf6ee` 象牙白底、`#bfa06a` 金、`#2e2519` 深墨、`#9a7d47` 強調、`#e2d7c4` 線；圓角 2px、1px 邊框、內容頁零陰影
- **字體**：Noto Serif TC（標題）／Cormorant Garamond italic（西文點綴）／Noto Sans TC（內文）
- **外部依賴**只有 Google Fonts CDN
- **素材** `assets/` 取自 `interval` repo 的真實產品圖（AI 生成畫作、空間照），皆 1024×1024
- `<meta name="robots" content="noindex">` — 網址公開但不進搜尋引擎索引
